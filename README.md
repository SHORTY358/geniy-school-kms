# Гений — центр репетиторства

Статичный презентационный сайт центра «Гений» в Комсомольске-на-Амуре.

## Состав

- `index.html` — структура и тексты;
- `styles.css` — адаптивный дизайн;
- `script.js` — меню, цены, FAQ, подбор занятия и фотогалерея;
- `assets/` — фотографии центра.

Сайт не требует сборки и готов для GitHub Pages.
